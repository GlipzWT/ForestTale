# ForestTale 🌲

**ForestTale** — консольная игра в жанре интерактивной сказки, вдохновлённая Undertale.  
Вы попадаете в таинственный лес, встречаете его обитателей и делаете выбор.  
Ваша доброта (или равнодушие) определяет финал. Никаких чисел, очков или подсказок — только история.

## Особенности
- 🎨 Цветной вывод и эффект печатной машинки.
- 🧭 4 встречи с разными персонажами (Эффи, потерянный Тень, Говорящий Цветок, Старый Камень).
- 💚 Скрытая система сострадания (игрок не видит очки).
- 🏆 3 концовки: от «Хранитель сердца» до «Первый урок».
- 🔁 Возможность переиграть.

### 1. Исходный код (Python 3.6+)
